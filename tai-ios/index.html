⬇️ TẢI FILE IPA
  1. Bấm TẢI FILE IPA để lưu file .ipa về máy (nên tải bằng máy tính).
  2. Dùng Sideloadly / AltStore / 3uTools, đăng nhập Apple ID của bạn để tự ký lại và cài file .ipa lên iPhone.
  3. Vào Cài đặt → Cài đặt chung → VPN & Quản lý thiết bị → chọn hồ sơ của bạn → Tin cậy.
  4. Mở game, đăng nhập (GT2). Thử nút Map góc trên-trái màn đăng nhập.
⚠️ Đây là bản IPA chưa ký (unsigned) — KHÔNG cài trực tiếp / OTA được. Bạn phải tự ký lại bằng Sideloadly / AltStore (đăng nhập Apple ID của bạn) rồi mới cài được. (Do tài khoản Apple Developer đang tạm khóa.)
